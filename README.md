# 明日方舟风格主界面 · 学习用复刻（ak-home）

**直接打开**：https://hykhxy.github.io/ak-home/

纯静态，无构建、无依赖、无后端。手机和电脑浏览器都能打开，建议横屏或电脑访问（界面是 1920×1080 等比缩放舞台）。

| 页面 | 内容 |
|---|---|
| 大厅 | 432 名干员立绘切换、视差光影、粒子、斜切转场、点击立绘播放语音 |
| 干员 / 仓库 | 干员档案与 1118 项道具 |
| 编队 | 4 队 × 12 格 |
| 任务 | 日常 / 周常 / 主线 / 支线，每天 04:00 重置 |
| 作战 | 出击与结算 |
| 角色语音 | 17637 条台词，**中文 / 日语游戏原声**（线上从 jsDelivr 加载） |
| 基建 | 制造站 / 贸易站 / 发电站 / 宿舍 / 会客室 / 加工站 / 办公室 / 控制中枢，干员技能、心情、电力、无人机、订单 |
| 活动「泰拉纪事」 | 31 篇原创世界观转述、泰拉问答、活动任务、印记兑换 |
| 创造角色 | 扮演原著博士，或原创角色（姓名/性别/性格/身材样貌/衣着/头像/天赋/属性面板） |

存档保存在浏览器 localStorage（`ak.state.v2`），不同网址（线路）的存档各自独立，清除浏览器数据会丢失存档。

## 语音说明
语音原声不随本仓库托管（约 1.5GB），线上通过 jsDelivr 读取 [isHarryh/Ark-Voice](https://github.com/isHarryh/Ark-Voice)（固定在提交 `79584841`），自动在 fastly / quantil / testingcf / cdn 四条线路间回退。首次播放某位干员的语音需要下载该干员的整合音频（约 1–2MB）。网络封锁 jsDelivr 时，语音会退回浏览器 TTS 或提示音。
